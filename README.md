Sistema de gerenciamento financeiro desenvolvido para controle de **créditos, débitos, usuários e congregações**.

O projeto possui autenticação, controle de permissões, geração de relatórios e integração entre frontend, API e banco de dados.

**Principais tecnologias:**

`Python` `FastAPI` `React` `PostgreSQL` `Supabase` `JWT`

### 🩺 EMPS — Sistema de Monitoramento

Projeto desenvolvido como **Trabalho de Conclusão de Curso**, envolvendo software, APIs, banco de dados, aplicação web/mobile e integração com sensores.

**Principais tecnologias:**

`Python` `FastAPI` `React Native` `JavaScript` `PostgreSQL` `Supabase` `Arduino`

[🔗 Ver projeto](https://github.com/LuixG-BR/TCC)
